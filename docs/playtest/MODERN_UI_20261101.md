# Modern UI refinement — 2026-11-01

## Design objective

User feedback: too many boxes; make the game UI more modern. Applied the project
`game-ui-ux`, `godot-ui-control`, and `game-design` skills: establish hierarchy
through grouping, spacing, type and state, preserve responsive container layouts,
and retain keyboard focus and readable localized text.

Design pillars: open workspaces, restrained decoration, clear actions, readable
state. Dark slate, bone text, amber selection and the game's fantasy imagery
remain. This is a presentation change, not a change to progression or combat rules.

## Changes

- Shared shell uses flat, borderless reading surfaces rather than repeating wood,
  cloth and copper nine-slice frames. Section styles are transparent. Dialogs
  retain opaque reading surfaces; focused controls retain a visible outline.
- Sans-serif body text and data; serif retained for the title wordmark and major
  contract/result titles. The 22px body / 18px minimum contract is unchanged.
- Contract and result lanes use open groups and thin separators. Statistics are
  unboxed. Expanded result evidence uses two wrapping columns. Primary actions
  have restrained amber emphasis.
- Equipment, forge, training and proxy pages use unframed sections and compact
  informational rows. Interactive equipment slots still distinguish selection.
  The old per-pixel border-darkening cache is removed.
- Icons no longer add an ornamental backing. Talent/law icons reuse the original
  transparent atlas silhouettes, preserving their mappings and pixel identities.
- Combat HUD panels and controls lose enclosing ornamental borders; semantic
  status accents and keyboard-focus treatment remain.
