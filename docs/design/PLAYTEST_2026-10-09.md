## 试玩方法

- 引擎：Godot `4.7.2-stable_linux.x86_64`。
- 渲染：Xvfb + Mesa llvmpipe，真实窗口渲染；非硬件 GPU 性能测试。
- 输入：`tools/play_session.py` 写入命令，`tools/play_session.gd` 创建 `InputEventKey/MouseButton/MouseMotion` 并交给引擎输入系统；没有调用按钮 `pressed.emit()`，没有合成胜利或直接改战斗状态。
- 时间：按帧推进输入。长按的帧数只表示测试机可重复的模拟帧，不冒充人类墙钟手速。
- 会话语义：命令之间与快照结束后默认 `PROCESS_MODE_DISABLED`；每条命令先恢复处理、等待一帧让真实输入进入当前界面，再执行事件与显式帧，最后重新暂停。未加入默默生效的实时模式。
- 隔离：试玩存档与缓存均使用独立目录；最终工具补验只设置独立 `XDG_*`，不覆盖 `HOME`/`CODEX_HOME` 或用户正式存档。

自然新档证据在 `build/current/playtest-2026-10-09/natural/`。其中 `input.jsonl` 是逐条引擎输入与动作后状态摘要，`engine.log` 是引擎命令日志，编号 PNG 是对应画面。

## 摩擦点与修复

### 1. 契约目标在画外，新玩家缺少下一步

- 之前：`02-town-entry.png` 的目标在镇内，但契约台与首段路线不在镜头内。要知道下一步应沿哪个 authored `routes_uv` 路点走，必须读布局或状态 JSON；这不能算画面已引导玩家。
- 之后：小镇在当前 640×360 镜头内显示一个小箭头，指向最近路线段的下一点；到达目标建筑镜头后隐藏。它不打开设施，也不提供全局菜单。
- 证据：`after-1280/after-1280-spawn-guide.png` 是新档进镇后不移动、等待 20 帧的首屏；对应 JSON 显示 `destination_guide.visible = true`、目标为 `contract`。行走中的 `after-1280/after-1280-road-guide-2.png` 与 `after-1600/after-1600-road-guide.png` 显示箭头随路线更新。

### 2. Tab 帮助承诺了地标选择，但启动画面没有可见地标

- 之前：帮助写“Tab 地标”，但出生镜头没有任何可见设施地标；状态中焦点为空，玩家无法确认 Tab 是否生效。
- 之后：帮助改为“Tab 选择可见地标”。Tab/Shift+Tab 只在当前镜头可见的地标之间循环，Esc 离开地标焦点并恢复行走。
- 证据：走动到验律场可见后，`after-1600/after-1600-tab-focus.json` 记录焦点为 `TownLandmark_training`；再按一次 Esc，`after-1600-landmark-escape.json` 焦点为空且位置不变。

### 3. 设施页 Esc 不执行画面上的固定返回动作

- 之前：设施页能看到固定返回按钮，但按 Esc 留在原页；自然流程中第 54 条输入在 `loadout` 按 Esc 后仍为 `loadout`。
- 之后：无弹窗时 Esc 等同页面固定返回；若焦点在搜索输入框，第一次 Esc 只离开文本编辑，不误触返回。
- 证据：`after-1280/after-1280-facility-before-esc.png` 显示设施页与返回动作，`after-1280-town-after-esc.png` 显示同一会话按 Esc 后回到小镇并保留镇内位置。输入/搜索焦点分支由 `targeted-tests/logs/test_playtest_comfort.log` 覆盖。

### 4. 结算、比较与返镇需要多次显式点击，Esc 不按层返回

- 之前：自然流程为结算 `09` → 比较 `10` → 装备页 `11` → 返镇 `12`，每一步都要找并点击明确按钮；Esc 不关闭装备详情，也不作为主返回。
- 之后：结算页 Esc 先关闭装备详情弹层；没有本地弹层时请求返回小镇。一次输入只执行当前层级的一个动作。
- 证据：自然路径截图展示旧动作链；`test_playtest_comfort.log` 验证一次 Esc 只产生一次返镇请求，且详情弹层打开时 Esc 只关闭弹层。

### 5. 搜索框 Esc 的状态只能靠源码/JSON 确认

- 之前：在筛选输入框按 Esc 后，画面没有足够反馈说明是退出编辑、关闭页面还是无动作；需要读焦点 owner 才知道结果。
- 之后：第一次 Esc 明确只释放文本编辑焦点，页面不返回；再次 Esc 才返回。测试同时断言返回请求计数不变。
- 证据：`test_playtest_comfort.log` 中的 facility search 分支；`tools/play_session.py` 现在也会导出当前界面的实际焦点路径。

## 画面引导审计

以下操作在修复前不能仅凭画面可靠知道，需要读源码或状态 JSON；因此不计入“画面已引导”：

- 契约目标的下一段路线点与箭头是否应显示。
- Tab 是否真的选中了建筑地标，尤其地标位于嵌套呈现视口时。
- 搜索框 Esc 后编辑焦点是否释放。
- Esc 会被哪个弹窗、文本编辑或页面返回分支消费。

修复后，前两项有直接画面与状态证据；后两项有输入计数和焦点路径回归。
