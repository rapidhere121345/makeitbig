# Scenery polish direction

The user rejected the brighter cartoon drafts after seeing them. Retain the
original ancient dark fantasy setting with subtle magical/cyberpunk accents.
Improve silhouette clarity, material grouping and quiet ground; use restrained
amber and cyan/violet emissive details. No cheerful green/tan palette.

The first bright loadout, pine and town_ground images under sources/ are
rejected drafts and are not runtime art. New approved-direction generation
uses coarse_sources/ and coarse_prompts/. Do not pack the rejected drafts.

User retained: slightly enlarged ground collision and less transparent faded
scenery. Target alpha 128/255, with opaque characters and real readability checks.

Latest clarification: VERY pronounced pixel art, large visible square clusters,
hard stepped silhouettes, limited palette, and no fine surface texture.
This changes rendering style, not the dark ancient setting.

Final direction: very coarse pixel clusters and fewer details, with softer interior
value transitions but stepped silhouettes. All 17 scenery families and both grounds
were generated as new whole assets. Character animation is retained.
