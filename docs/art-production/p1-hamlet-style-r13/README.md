# Current Town Production Sources

Current town materials, hearth, facilities, edges, lanterns, and residents have originals in sources/. PROVENANCE.json and PROMPTS.json record sources; style-recipe.json rebuilds the town, life-recipe-v02.json rebuilds current hamlet_life_r13/v02, and the commons original corresponds to hamlet_commons_r13. The hamlet_concept_v02 and hamlet_life_v01 recipe templates and their current originals are retained.
