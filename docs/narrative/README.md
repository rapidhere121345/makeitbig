# 剧情与世界观

当前 Demo 的首章对白位于 [chapter_one_story.json](../../content/chapter_one_story.json)：28段、每段2–4页，串起寒原旧路搜宝、五位镇民的变化与巨像开路后的返镇。阅读状态及真实发现的接口由 StoryProgression 与测试钉死，维护约定见 story 相关测试。

完整游戏的两份当前规划：

- [WORLD_BIBLE](WORLD_BIBLE.md)：世界事实、人物、地区、物品与美术语义。
- [STORY_AND_EXPERIENCE](STORY_AND_EXPERIENCE.md)：前中后期和终局的38个可重入体验单元、6条生活支线。

长稿中包含尚未实现的中后期内容。当前已实现范围以根 [README](../../README.md) 为准，不能用设计名词或字幕替代系统。

成长依靠探索、验证与积累。掉落提供可能性，结构成立、参数临界、实战可靠与挑战胜利分别记录；最后一件掉落可以补齐此前积累，但不单独交付整套下一阶力量。不强制固定配方、失败次数、刷取次数或历史阅读。

保留的世界核心是无真名的流浪者、应许教会、圣律与组合爆炸造成的大失控、哈姆雷特与守冬塔、小胜利结局及完整后期的更高增长层。具体边界和实现需求见两份长稿。
